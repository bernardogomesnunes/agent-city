# Agent City part 4: World Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `agentcity city` serves a Phaser 3 pixel village on 127.0.0.1 where agents walk to buildings that match their log activity, the user walks an avatar, approves at HQ, starts runs and types `agentcity` commands.

**Architecture:** New `world` package turns action-log rows into `CityState` (pure) and holds the shared map and protocol (`@agentcity/world/shared`, no Node imports). New `client` package (Vite, Phaser) draws it. `cli` gains a `city` command: HTTP static server, websocket, run host with a web approver, and an in-process terminal.

**Tech Stack:** TypeScript 6, Node 24, `phaser@3.90.0`, `vite@7`, `ws@8`, zod 4, better-sqlite3, vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-31-world-design.md`

## Global Constraints

- Import direction: `world` imports core and safety. `client` imports only `phaser`, `zod` and `@agentcity/world/shared`. `cli` imports world, org, safety, core. Add eslint `restrict` rules: world must not import org or cli; client must not import core, safety, org, cli, or `@agentcity/world` (root).
- `packages/world/src/shared/*` imports nothing from Node or other packages except zod.
- Server binds `127.0.0.1` only. Default port 4321. Token: 32 hex chars from `randomBytes(16)`.
- Websocket upgrade needs `t === token` and `Origin === http://127.0.0.1:<port>`. Else HTTP 403 and socket destroyed.
- Poll interval 250 ms. First poll reads the last 500 action rows.
- Map 40 x 30 tiles, 16 px tiles, scale 3. Agents walk 4 tiles per second.
- Building ids: `director`, `hq`, `software`, `visual`, `plot-1` to `plot-6`. Plot kinds: `library`, `workshop`, `exchange`, `studio`, `house`.
- `stopped` shows 5000 ms, then `idle`.
- `lastText` max 60 chars, redacted with the server's secrets.
- All art is original. No Nintendo or Game Freak assets, names or fonts. Overlay text uses CSS `font-family: monospace` (ruling: the spec's "pixel font drawn in code" is dropped for version 1; the overlays keep the GBA box style).
- Commit messages end with the attribution trailer the controller gives.
- Every subagent prompt carries: "No mannered prose. Answer first, short sentences, numbers and names, end on the result."

## Review Focus

1. Two browser tabs open at once: both get snapshots and patches; an approve from one resolves for both. Test in Task 6.
2. Server stopped with Ctrl+C while a city run waits for approval: pending approvals denied, run aborted, process exits 130. Test in Task 6.
3. An agent created while the city runs appears without restart: the poller re-reads `AgentStore.list()` every poll. Test in Task 4.
4. Typing in the terminal or goal box must not move the avatar or toggle roofs. Test in Task 10 (key-focus guard function).
5. A `build` for a plot claimed between gate check and tool run returns `plot <n> is taken` text, no throw. Test in Task 2.
