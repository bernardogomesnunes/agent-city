# Part 4 (World) visual direction

Date: 2026-10-31. Source: the user, during part 2.

## Look

- Top-down 2D pixel art in the style of Game Boy Advance era monster-catching RPGs (the user's reference: Pokémon Ruby and Sapphire).
- Applies to the whole city: houses, paths, plots, UI panels, dialog boxes, menus.
- All art is original. No Nintendo or Game Freak sprites, tiles, fonts, music or names. Match the style (16x16 tiles, bright palette, soft outlines, 3/4 roofs), not the assets.

## Roofs

- A global toggle removes every roof, so agents are visible inside buildings.
- Entering a building removes that building's roof only.

## Buildings at start

1. Director's house: home of the Boss agent.
2. Headquarters (larger): planning, dashboards, assignments, current state, agent creation.
3. Software house: coding work.
4. Visual house: design and visual work.

The user named these as "3 buildings" but listed 4; confirm in the part 4 brainstorm.

## Growth

- Empty plots around the start buildings.
- Agents build new buildings on plots as projects grow (ties to the brief: "buildings appear as projects grow").

## Also for parts 4 and 5

- Integrated terminal panel in the city UI (part 4).
- Chat with agents in the city (part 5).

## Update 2026-10-31: reference screenshot

The user shared a later-generation (DS era) city screenshot and asked for "more like this style". Traits to match with original art:
- Gray-mauve cobblestone plaza paths, mint-green grass, brown rocky cliff terraces, raised flower beds, stone signposts.
- Buildings as whole prefab images with strong outlines, saturated roofs, eave shadows, lit windows.
- Distinct silhouettes per building: HQ is a tall tower block; the visual house has a tent or dome top.
- Roofs stay removable: each building has a base layer (interior visible) and a roof layer.
